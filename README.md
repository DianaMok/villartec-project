# VILLARTEC Project

Responsive website built with HTML5, SCSS/CSS and vanilla JavaScript. An independent frontend practice project inspired by the VILLARTEC website.

## Live Demo

[View the website](https://dianamok.github.io/villartec-project/)

## Technologies

- HTML5
- SCSS / CSS3
- JavaScript
- Splide.js
- CSS Grid / Flexbox
- Git / GitHub

## Features

- Responsive layout for desktop, tablet and mobile
- Dropdown catalog and mobile navigation
- Product cards and interactive sliders
- News and articles carousel
- Search interface with suggestions
- Dealer application modal with client-side validation
- Sliding shopping cart interface (work in progress)
- Responsive footer and contact form

This is a frontend demonstration project, not the official VILLARTEC website. Form submission to a production server and checkout are not connected.
